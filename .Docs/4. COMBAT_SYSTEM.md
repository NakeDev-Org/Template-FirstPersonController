# Montagem do Sistema de Combate (Guia Definitivo)

Este documento detalha o passo a passo exato para configurar o combate (armas de fogo e corpo-a-corpo) no seu jogo, direto na Unity. Sem explicações teóricas, apenas o "Mão na Massa".

---

## 1. Criando os Dados da Arma (ScriptableObjects)
Antes de equipar uma arma no Player, você precisa definir os status dela.

1. Vá na aba `Project` e escolha uma pasta (ex: `Assets/Data/Weapons`).
2. Clique com o botão direito `Create > NakeD > Combat > Ranged Weapon Data` (para armas de fogo) ou `Melee Weapon Data` (para facas/machados).
3. Selecione o arquivo criado e preencha no Inspector:
   - **Base Damage**: O dano (ex: `20`).
   - **Time Between Shots**: (Ranged) Intervalo de tiro (ex: `0.5`).
   - **Hit Mask**: (Ranged) Mude para `Default` e `Enemy` (garanta que a layer do Player NÃO esteja marcada).

---

## 2. Configurando o Cano da Arma (Muzzle)
O tiro (Raycast) precisa saber de onde sair fisicamente.

1. Na sua cena, abra a hierarquia do seu **Player** e encontre o modelo 3D da arma que está na mão dele.
2. Vá até a ponta exata do cano da arma.
3. Clique com o botão direito e crie um **Empty GameObject**. Nomeie como `MuzzlePoint`.
4. Ajuste a rotação do `MuzzlePoint` para que a setinha Azul (Eixo Z/Forward) aponte exatamente para frente (na direção do tiro).

---

## 3. Configurando o Player (`PlayerCombatAddon`)
Agora vamos conectar a arma ao personagem.

1. Selecione o objeto raiz do seu **`Player`**.
2. Vá até o componente **`PlayerCombatAddon`**.
3. Arraste a **MainCamera** (a câmera que renderiza o mundo) para o campo `FPS Camera`.
4. Arraste o **`MuzzlePoint`** que você criou no Passo 2 para o campo `Muzzle Point`.
5. Arraste o **ScriptableObject** (o arquivo de dados da arma que você criou no Passo 1) para o campo **Current Ranged Weapon** ou **Current Melee Weapon**.
6. (Opcional) Ative o checkbox `Is Melee Stance` se você quiser que o clique do mouse dispare soco/faca ao invés de atirar.

---

## 4. Configurando um Inimigo para Morrer
Para testar o tiro, você precisa de um alvo que receba o dano.

1. Crie um cubo na cena (`GameObject > 3D Object > Cube`) ou arraste seu modelo de Zumbi.
2. Certifique-se de que ele tem um Collider (ex: `BoxCollider` ou `CapsuleCollider`).
3. Mude a Layer dele para `Enemy` (se você configurou a arma para atirar apenas em Inimigos).
4. Crie um novo script C# simples no seu projeto, por exemplo, `ZombieHealth.cs`:

```csharp
using UnityEngine;
using nakatimat.DamageSystem;

public class ZombieHealth : MonoBehaviour, IDamageable
{
    public float health = 100f;

    public void ApplyDamage(float damageAmount, GameObject attacker = null)
    {
        health -= damageAmount;
        Debug.Log("Zumbi levou tiro! Vida restante: " + health);

        if (health <= 0)
        {
            Destroy(gameObject);
        }
    }
}
```

5. Adicione este script ao seu Cubo/Zumbi.

## 🎉 Conclusão
Pronto! Dê Play no jogo. Quando você clicar o botão de ataque, o `PlayerCombatAddon` vai disparar o hitscan diretamente pelo `MuzzlePoint`, e o Zumbi vai receber o dano instantaneamente!
