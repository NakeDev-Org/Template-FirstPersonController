# Montagem do Sistema de Interação (Guia Definitivo)

Este documento detalha o passo a passo prático para configurar objetos interativos (portas, itens, bilhetes) na sua cena, sem escrever código.

---

## 1. Configurando a Layer
A Unity precisa saber o que é interativo e o que é apenas cenário.

1. Vá em `Edit > Project Settings > Tags and Layers`.
2. Em **Layers**, crie uma nova layer chamada **`Interactable`**.

---

## 2. Configurando o Player (O Scanner)
O seu Player precisa conseguir "enxergar" os objetos interagíveis.

1. Selecione a **MainCamera** (a câmera dentro da hierarquia do seu Player).
2. Adicione o script **`InteractionScanner`** nela.
3. No Inspector do `InteractionScanner`:
   - **Interactable Layer**: Selecione a layer `Interactable` que você acabou de criar.
   - **Scan Range**: Defina a distância máxima que o jogador pode interagir (ex: `2` metros).
   - O Player agora vai soltar um Raycast invisível do centro da tela o tempo todo procurando itens.

---

## 3. Criando um Objeto Interativo na Cena
Vamos transformar um cubo comum em algo que o jogador pode clicar.

1. Crie um objeto na cena (`GameObject > 3D Object > Cube`) e nomeie como `Key_Item`.
2. **[CRÍTICO]** Mude a Layer deste cubo para **`Interactable`** no topo do Inspector.
3. Adicione o componente **`InteractableObject`** no cubo.
4. No componente `InteractableObject`:
   - **Interaction Prompt**: Escreva `"Pegar Chave"`.
   - **On Interact (UnityEvent)**: Clique no botão `+`. Arraste o próprio `Key_Item` para a caixinha vazia, clique no menu dropdown e selecione `GameObject > SetActive (bool)`. Deixe a caixa desmarcada. (Isso fará o objeto sumir quando clicado).

---

## 4. Usando ScriptableObjects para Ações Avançadas
Se quiser tocar um som ou fazer coisas mais complexas do que um simples UnityEvent, use as "Ações".

1. Vá na aba `Project` e clique com o botão direito `Create > NakeD > Interactions > Play Animation Action SO` (por exemplo).
2. Selecione o arquivo criado e configure qual animação você quer tocar.
3. Volte no seu cubo `Key_Item` na cena.
4. No componente `InteractableObject`, expanda a lista **Actions To Execute**.
5. Clique no `+` e arraste o ScriptableObject que você acabou de criar para dentro da lista.
6. Agora, quando o jogador clicar na chave, o UnityEvent será executado E o ScriptableObject será disparado ao mesmo tempo.

---

## 5. Posição da UI (O Ícone Flutuante)
Por padrão, se o Player olhar para a chave, o texto "Pegar Chave" vai flutuar no meio do cubo. Se quiser ajustar a altura:

1. Selecione o cubo `Key_Item`.
2. No componente `InteractableObject`, encontre a variável **UI Offset**.
3. Altere o valor de Y (ex: `Y = 0.5`) para empurrar o texto um pouco mais para cima.
4. (Opcional) Você pode criar um GameObject vazio dentro da chave (ex: `IconPivot`), posicioná-lo onde quiser, e arrastá-lo para o campo **UI Pivot**. O ícone aparecerá exatamente ali.

## 🎉 Conclusão
Pronto! Dê Play no jogo. Aponte a câmera para o cubo. O texto "Pegar Chave" deve aparecer na tela (se a sua UI de interação estiver configurada no Canvas). Quando apertar o botão de interação, o cubo vai sumir!
