# NakeDev.EditorTools

Esta pasta é reservada exclusivamente para o polimento visual e ferramentas do Editor da Unity (KISS).
Tudo o que for PropertyDrawer, CustomEditor, e Menus de Atalho customizados (como a estilização do nosso ComboGraph) ficará armazenado aqui no futuro.

Mantemos essa lógica isolada para não misturar com o código "Runtime" (que roda no jogo de fato).
